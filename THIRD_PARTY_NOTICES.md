## Faculty expansion assets

The forest battle background `spr_battlebacks_free.png` is extracted from the user-provided Free Sample pack. The included notice is `(c) Yanako RPGs LLC 2022`; the original notice is retained in `assets/game/faculty/yanako-credit.txt`. The sample image containing baked-in battle UI is not used as the arena.

Trainer portraits are cropped from Screensmith's Townspeople trainer sheet. They are fictional game representations, not verified portraits of the faculty members. Dialogue is written for this game and is not quoted from the real faculty.

The additional music tracks are the user-provided `03. A New Beginning.mp3` and `trainer battle.mp3`. Additional Gen 3 SFX: Ice Beam, Blizzard, Confusion, Psychic, Bite and Crunch. These have the same classroom-only status described above.

Fifteen existing animated creature sheets from graphics.zip are used. Selected visual forms are reassigned to game IDs to contrast small companions with larger bosses; game names and elemental assignments are game design choices. The exact mapping is recorded in `docs/IMPLEMENTATION_STATUS_V2.md`.

`docs/pouch-animation-sample.png` is an AI-generated front/back animation review sample based on the supplied Pouch sprite. It is not yet used as production animation; bulk art awaits the user's review.


## Approved refinement audio and map preview
V3 uses the user-provided `1-10. Victory!(afterfinish catch pokemon and finish trainer) (Wild Pokémon).mp3` after a successful capture or faculty battle. It has the same classroom demonstration status as the other Pokémon-derived recordings. Wild battles now always use `Pokemon Battle music.mp3`; faculty battles use `trainer battle.mp3`.
The user supplied Kanoko Town, Pokemon Battle music, and A New Adventure recordings for classroom demonstration. These are not represented as original compositions or as licensed for public distribution. Existing selected Gen3 SFX remain in use.
Expo Go uses a Leaflet 1.9.4 / OpenStreetMap preview because its Google Maps SDK returned Authorization failure. OpenStreetMap attribution remains visible. Native standalone Android retains react-native-maps with the existing Google Maps configuration. Tile requests use the default browser cache and identify ECHO HUNT; no offline tile prefetch is used.
